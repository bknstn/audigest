# Safety, privacy, and fixture rules

Audigest reads audio, video, transcripts, captions, and text that may contain private, copyrighted, or otherwise sensitive material. Users are responsible for having the rights and permissions needed to process the files they supply. Keep processing local by default and make any future external provider use explicit.

## Files, media, and caches

- Never commit API keys, access tokens, cookies, private downloaded media, or user transcripts.
- Never persist credentials in transcript files, cache metadata, configuration defaults, or generated output. The OpenAI provider reads only `OPENAI_API_KEY`, and ElevenLabs reads only `ELEVENLABS_API_KEY`, from the environment. Local Whisper reads `AUDIGEST_WHISPER_MODEL_DIR` only to locate a local model directory; its full path is not stored in transcript metadata.
- Do not log secrets, authorization values, complete request headers, or full private transcript content in diagnostics.
- `summarize <transcript-id>` reads only the stored canonical transcript and writes separate processor artifacts; it never accesses the original source or invokes STT. A cache hit and the default `auto` provider make no model request. Only an explicit OpenAI selection on a cache miss sends the transcript title and indexed segment text to the fixed OpenAI API endpoint. The serialized request is capped at 256 KiB, uses the key from `OPENAI_API_KEY`, disables response storage and tools, and stores no credential or provider response object in the canonical transcript.
- Keep caches, `.env` files, model files, media, and generated transcripts out of version control with `.gitignore` rules.
- A local original media, transcript, caption, or text file is user-owned input: read it in place; never copy it into the cache, modify it, or delete it.
- Direct remote media downloads are streamed to temporary storage, removed after processing by default, and limited to 100 MiB. `--keep-media` retains successfully processed downloads only under the configured cache with a hashed filename; it never grants permission to copy, overwrite, or remove a local original. Existing retained paths are reused only when they are regular files containing the same bytes; symlinks and differing files are left untouched and cause an error.
- Cache pointers must distinguish source URI, effective content fingerprint (including selected sidecar contents), and requested language so changed local files or sidecars cannot reuse stale transcripts. Preserve actual provider/model provenance in the transcript, but do not let fallback provider selection suppress a valid matching cache entry.
- `show <transcript-id>` reads only an existing canonical transcript from the local cache. It must not inspect the original source, select a provider, invoke acquisition/STT, or modify cache artifacts.
- Do not add telemetry in the MVP.

`apply <transcript-id> --project <directory>` reads only the stored canonical transcript and the default `README.md` or explicitly named relative UTF-8 files. It does not scan recursively, expand globs, run commands, or modify project files. Reject absolute, traversing, hidden, escaping, symlinked, and non-regular context paths before reading; use no-follow, nonblocking opens and verify regular files. Limit input to 16 files and 64 KiB total, reject empty or invalid UTF-8 context, and cap serialized provider input at 256 KiB. Only an explicit OpenAI selection on a cache miss sends transcript title/segments plus selected relative filenames and file text. Cache paths must resolve outside the project; application artifacts retain only the project basename and selected relative filenames/content hashes, not the project root.

`english <transcript-id> --level <CEFR>` reads only a stored canonical transcript and never accesses its original source or invokes acquisition/STT. Require A1, A2, B1, B2, C1, or C2; allow zero items when the transcript contains no useful English material. Reject empty transcript text. Only explicit OpenAI selection on a cache miss sends the title, requested level, and indexed segment text; cap serialized input at 256 KiB, disable tools and response storage, and keep credentials out of artifacts. Validate each exact source quote and its expression before caching and again on cache hits. Keep generated examples separate from source context and copy timing/speaker only from canonical segments.

## Fixtures and test data

- Prefer short fixtures that are fully synthetic and generated for tests, or material whose redistribution permission is documented and clear.
- Synthetic audio may contain generated tones/noise or newly written, non-identifying speech. Synthetic `.txt`, canonical JSON, SRT, and VTT fixtures must be authored for the test and must not reproduce real users' transcripts, private conversations, or copyrighted source material.
- Do not add a real podcast/video excerpt, downloaded media, user recording, credentials, cookies, provider response containing personal data, or an actual cached transcript to the repository.
- When testing third-party source adapters in future work, mock their boundary with synthetic metadata/caption payloads; do not make live network requests in normal CI.
- Keep fixture content minimal and document the origin and license for any redistributable fixture.

## Network and source boundaries

- `ingest` reads local canonical transcript JSON, UTF-8 text/Markdown, SRT/VTT captions, deterministic adjacent sidecars, explicitly supplied direct HTTP(S) transcript/caption URLs, direct HTTP(S) media URLs, and public single-video YouTube watch/shorts/embed/`youtu.be` URLs before considering STT. `--transcript` takes a local transcript file or direct transcript URL and is valid only with media, including YouTube; it takes priority over sidecars, YouTube metadata/caption lookup, cache lookup, and STT. Remote transcript and YouTube caption bodies are limited to 2 MiB; remote media downloads are streamed and limited to 100 MiB. HTTP GETs use a 15-second socket timeout, a 60-second total deadline, and at most five manually validated redirects. URL userinfo and non-HTTP(S) redirects are rejected. Source/origin URIs omit query and fragment values; a one-way hash of the full direct URL locator distinguishes direct URL cache entries. YouTube caption identity instead uses the stable video ID, selected language/kind/format, and caption bytes; signed track URLs never enter artifacts. YouTube metadata uses the optional `yt-dlp` extra in a subprocess bounded to 60 seconds and 4 MiB output, with stderr discarded and user config/plugins/cookies/cache directories/remote components/geo bypass/update checks disabled. It rejects private, age-restricted, live, and upcoming videos. Caption discovery runs before STT; malformed or failed selected captions must not trigger STT. If captions are unavailable, check matching STT cache before fetching direct audio-only media. That cache uses video ID and title/uploader/duration/upload-date metadata as its freshness fingerprint, allowing a hit to skip audio download; if audio changes without changes in those metadata fields, an older STT result may be reused. Source/origin URIs omit signed query values. `transcribe` accepts local media only and skips acquisition and sidecar inspection. OpenAI and ElevenLabs STT are available only when explicitly selected as fallbacks after acquisition for `ingest`, or as the selected providers for `transcribe`. `auto` never selects an STT provider or reads `OPENAI_API_KEY` or `ELEVENLABS_API_KEY`.
- For `ingest`, a malformed existing transcript/text/caption candidate must fail clearly. Never skip malformed user content and invoke STT in its place; that could send audio to a provider or incur an unexpected cost. Explicit `transcribe` intentionally ignores adjacent sidecars.
- STT is a fallback for `ingest` and the explicit operation of `transcribe`. `ingest` must not let `--provider` override a usable transcript or caption. `transcribe` accepts supported local media only and ignores adjacent transcript/caption sidecars. Both commands reuse matching valid STT cache entries before calling a provider; `auto` remains cache-only and must fail clearly on a cache miss.
- Canonical segments may omit timing. A segment's start and end must either both be absent or both be valid timestamps. Renderers must not invent timestamps for untimed text.
- Direct transcript/media retrieval, YouTube metadata/caption acquisition, and OpenAI/ElevenLabs STT use explicit source/provider adapters, bounded timeouts, and sanitized errors. Local Whisper is available only through explicit `--provider local` selection and only with a prepared CTranslate2 model directory containing `model.bin`, `config.json`, and `tokenizer.json`; always use `local_files_only=True` and never download model/tokenizer files implicitly. Local inference runs on CPU/int8 and reads user media in place. A supplied transcript for remote media or YouTube prevents media retrieval; for YouTube it also prevents metadata/caption lookup. Direct transcript URLs and usable YouTube captions never send media to an STT provider; malformed selected documents fail before provider selection. Do not add hidden network calls or send media anywhere without an explicit user-selected provider.
- Never bypass authentication, paywalls, DRM, or access controls. Respect platform terms and copyright.
- Spotify support, if implemented later, may resolve public metadata and map an episode to its publisher-hosted RSS enclosure. Never download or rip audio from Spotify streams. If a mapping is ambiguous, report the available metadata and fail rather than guessing.
- Use environment variables for provider credentials. OpenAI accepts only `OPENAI_API_KEY` and ElevenLabs accepts only `ELEVENLABS_API_KEY`; local Whisper uses `AUDIGEST_WHISPER_MODEL_DIR` for an existing model directory, not credentials. Never add persisted config-file secrets without documenting their filesystem and security implications.

## Scope guard

`ingest` acquires existing local transcript/caption/text data, explicitly supplied direct transcript URLs, direct media URLs, and captions for public single-video YouTube sources. An explicitly supplied `--transcript` takes priority and avoids remote media download; for YouTube it also avoids metadata and caption requests. If no usable YouTube captions exist, use matching cached STT before downloading a direct audio-only format, and download only when an explicit STT provider is selected. Automatic publisher discovery, feeds, and Spotify metadata routes remain future slices. `transcribe` is the explicit STT-only path for supported local media and skips acquisition. The deterministic fake provider is an offline fallback; OpenAI and ElevenLabs are available only when the user explicitly selects the corresponding provider and supplies its API key. Local Whisper is available only when explicitly selected with a prepared local CTranslate2 model directory. `auto` reuses matching valid cached results appropriate to each command and otherwise fails without selecting an STT provider, even when API keys or a local model directory exist. The `summarize` processor also uses `auto` as a cache-only default; an OpenAI model request requires explicit selection and reads only `OPENAI_API_KEY`. The user has authorized the remaining North Star MVP items listed in `ROADMAP.md` for sequential, parent-reviewed iterations; implement only the currently selected item. RAG, embeddings, databases, GUI, background jobs, and telemetry remain out of scope.
